# Stage 1 训练损失曲线审查

## 目的与方法

针对 Subject 1、seed 42 的正式 Stage 1，检查完整 300 epochs 的训练目标是否持续改善及后期收益。图的结论是训练损失下降且后期收益明显减小；不把训练损失下降解释为泛化或重建质量提高。

使用完整 15,600 条更新日志，步骤连续，每个 epoch 52 次更新，无删行、缺失或非有限损失值。图中每个点为该 epoch 全部 52 个 batch 的算术平均，未额外平滑。单次训练种子，没有独立实验重复，故不绘制种子置信区间。CSV 中额外保存 batch 间标准差，该值不代表泛化误差或种子方差。

图采用 Python 的四面板定量布局：a 展示全程趋势；b 放大 200–300 epochs 检查晚期收益；c 展示图像、文本与四层特征的加权 MSE；d 展示图像和文本 SoftCLIP。c/d 使用对数纵轴且数据均大于零；a/b 使用线性纵轴，b 的轴范围已明确标为放大。MSE 为 L2 归一化后乘以 200000 的损失项，不是原始 MSE。四层 SoftCLIP 项在训练代码中设计为零，不作为独立有效目标绘图。总 loss 等于六个 MSE 与两个有效 SoftCLIP 项之和，已逐条核验。

第 1 至 300 轮下降 85.70%；第 200 至 300 轮下降 4.56%；第 250 至 300 轮下降 0.86%；第 275 至 300 轮下降 0.21%。这些比例比较指定 epoch 的均值，不是窗口均值。最后 25 个 epoch 的均值范围为 3.710717–3.729817，存在正常的局部波动；不能声称逐轮严格单调。

六个 MSE 和两个 SoftCLIP 分量整体下降并在后期变缓，没有观察到持续的训练损失恶化。第 300 轮均值 3.718562 与最后一次更新的 loss 3.740127 是不同统计量。

## 解释与限制

训练目标优化有效，约 250 epochs 后收益已很小，适合作为检查训练预算的信号。学习率也按预设余弦调度下降到峰值的 0.01，因此后期曲线变平本身不是已验证的早停规则。

当前没有独立验证集曲线。仅凭这些训练记录无法判定是否过拟合、哪一轮重建效果最佳，或最后 50 轮是否在泛化上值得。不能由本图事后宣布第 250 轮为最优 checkpoint。正式测试集不能用于选模或早停；原训练已见样本不能事后称为独立验证集。本次只读取日志并保存分析，不替换编码器、不修改运行中的 Stage 2、不改变既有 checkpoint 保留策略。
